Phase 3 Dev Sandbox

Faculty API Playground

Test the faculty CMS endpoints. Reads are public — writes need a login session from the Auth Playground (same browser, cookies are shared).

1. List Faculty — GET /v1/faculty

Public. Supports ?search=, ?page=, ?limit=.

2. Profile Detail — GET /v1/faculty/:slug

Public. Returns profile + publications, projects, patents, seminars, supervisions.

3. Edit Profile — PATCH /v1/faculty/:id 🔒

Requires login as admin or the faculty owner (same email). Log in via the Auth Playground first.

4. Add Publication — POST /v1/faculty/:id/publications 🔒

Same auth rule. Resources: publications, projects, patents, seminars, supervisions.

To test DELETE: create an item, copy its id from the console, then run
DELETE /v1/faculty/:id/:resource/:childId via the console button below.
